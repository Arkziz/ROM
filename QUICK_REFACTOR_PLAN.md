### Етап 2: Розбиття db.py на файли (2-3 години)

**Створюємо файли:**

```
db_modules/
  __init__.py              # Re-export всіх функцій для сумісності
  connection.py            # conn, cursor, init_db()
  user.py                  # ~40 функцій для users
  inventory.py             # ~50 функцій для inventory + items
  equipment.py             # ~60 функцій для equipment slots
  combat.py                # ~30 функцій для combat stats
  economy.py               # ~40 функцій для gold, shop, trading
  quests.py                # ~50 функцій для contracts + daily quests
  character_class.py       # ~30 функцій для class system
  runes.py                 # ~40 функцій для rune system
  regeneration.py          # ~20 функцій для HP/MP/Energy regen
  shop_preview.py          # ~30 функцій для shop previews
  testing.py               # ~30 функцій для dev/testing
  migrations.py            # ~20 функцій для migrations
```

**Compatibility layer в db.py:**
```python
# db.py стає просто re-export файлом
from db_modules.connection import conn, cursor, init_db
from db_modules.user import *
from db_modules.inventory import *
from db_modules.equipment import *
# ... і так далі
```

**Результат:**
- Весь існуючий код працює без змін
- `from db import create_user` все ще працює
- Але тепер можна редагувати окремі файли

**Коміти:**
1. "Розбити db.py: user + inventory"
2. "Розбити db.py: equipment + combat"
3. "Розбити db.py: economy + quests + runes"
4. "Розбити db.py: інші модулі + compatibility layer"

**Час AI:** ~2-3 години
