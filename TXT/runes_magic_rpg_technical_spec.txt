2. Реєстрація персонажа

2.1. Логіка /start

При команді:
/start

бот виконує:

1. Перевірити наявність користувача.
2. Якщо користувача немає — створити.
3. Якщо немає character_name — попросити ввести ім’я героя.
4. Якщо немає character_class — показати вибір класу.
5. Якщо ім’я і клас уже є — одразу показати головний екран.

2.2. Ім’я персонажа

Поле:
users.character_name

Правила:

мінімум: 2 символи
максимум: 24 символи
заборонені службові символи: / \ < > { } [ ] |

У текстах реєстрації не вказувати приклади імен.

2.3. Клас персонажа

Поле:
users.character_class

Доступні класи:

warrior  → 🛡️ Воїн
knight   → ⚔️ Лицар
scout    → 🏹 Скаут
rogue    → 🗡️ Розбійник
mage     → 🔮 Маг
priest   → ⚕️ Жрець


3. Зміна класу

3.1. Предмет

Предмет:
🔮 Сфера нового шляху

ID:
301

Тип:
type = class_reset
category = potion
rarity = epic

3.2. Логіка використання

1. Гравець відкриває інвентар.
2. Переходить у категорію зілля / особливі предмети.
3. Натискає 🔮 Сфера нового шляху.
4. Натискає "Використати".
5. Предмет зменшується на 1.
6. users.class_change_available = 1.
7. Відкривається меню вибору нового класу.
8. Після вибору класу class_change_available = 0.

3.3. DEV-команда

/sphere [quantity]

Видає Сферу нового шляху для тестування.

5. HP / MP / енергія

5.1. HP

Поточне HP:
get_current_hp(user_id)

Максимальне HP:
get_max_hp(user_id)

Після смерті:
HP відновлюється до максимуму.

5.2. MP

MP використовується тільки класами:
🔮 Маг
⚕️ Жрець

Формула max MP:
max_mp = 50 + INT × 5 + WIS × 3

Правило зміни екіпірування:

Якщо max_mp збільшився — current_mp не має автоматично ставати максимумом.
Якщо max_mp зменшився — current_mp обрізається до нового max_mp.

Поточне тестове правило:
Після завершення бою MP повністю відновлюється до максимуму.

Події завершення бою:
перемога
смерть
втеча

У майбутньому можлива зміна балансу:
звичайний бій: +50% MP
елітний бій: +100% MP
смерть: +100% MP
втеча: +0–25% MP

5.3. Пасивний реген поза боєм

Було додано систему:
+5% max HP за 1 хвилину
+5% max MP за 1 хвилину для mana-класів

Але через поточне правило повного MP після бою ця система в основному актуальна для HP.


6. Класові ресурси

6.1. Воїн / Лицар — Лють

Ресурс:
🔴 Лютість

Старт бою:
0/100

Набір:
+15 Люті за атаку / атакуючу навичку
+10 Люті за отриману шкоду

Ухил не дає Лють.

Формула:
new_rage = min(100, current_rage + gain)

6.2. Скаут / Розбійник — Енергія

Ресурс:
🟡 Енергія

Старт бою:
100/100

На початку реального ходу:
+20 Енергії

Формула:
new_energy = min(100, current_energy + 20)

6.3. Розбійник — Комбо

Ресурс:
⚔️ Комбо

Старт бою:
0/3

Набір:
Підступний випад: +1 комбо
Криваве слідування: +1 комбо

Фінішер:
Потрошіння витрачає всі комбо-очки.

Формула:
new_combo = min(3, current_combo + gain)

6.4. Маг / Жрець — Мана

Ресурс:
🔵 Мана

У бою витрачається навичками.

Після бою зараз:
MP = max_mp


7. Бойова система

7.1. Початок бою

При натисканні:
🔎 Полювання

бот:

1. Перевіряє HP > 25%.
2. Перевіряє, чи персонаж не переріс локацію.
3. Витрачає енергію полювання.
4. Генерує моба.
5. Ініціалізує:
   - max_hp моба
   - potion_cooldown
   - stunned_turns
   - skill_cooldowns
   - enemy_effects
   - player_effects
   - класовий ресурс
6. Показує старт бою.

7.2. Формула шкоди

Фізичний захист:
PDEF = PDEF екіпірування + STA × 0.2 + заточка

Магічний захист:
MDEF = MDEF екіпірування / біжутерії + WIS × 1 + заточка

Шкода:
damage = attack - defense × 0.5

Мінімум:
damage >= 1

Фізична шкода використовує PDEF.
Магічна шкода використовує MDEF.

7.3. Крит

У профілі показуються:
фізичний крит
магічний крит
базовий ухил
крит ворога по гравцю

Поточна логіка display:
physical_crit = 5 + ((DEX - 10) / level) × 0.5
magical_crit = 5 + ((WIS - 10) / level) × 0.5

Обмеження:
мінімум 1%
максимум 35%

Крит ворога по гравцю:
enemy_crit = max(0, 10 - STA // 25)


8. Навички класів

8.1. Загальна логіка навичок

У бою є кнопка:
✨ Навички

Меню навичок:

1. Показує всі навички класу.
2. Показує ресурс.
3. Показує вартість.
4. Показує cooldown.
5. Якщо навичка доступна — callback use_skill.
6. Якщо навичка на cooldown — callback skill_locked.

8.2. Cooldown-и

Cooldown зменшується тільки при реальному ході:
⚔️ Атакувати
доступна ✨ Навичка

Cooldown не зменшується при:
відкритті меню навичок
натисканні заблокованої навички
поверненні назад
використанні зілля

9.3. DoT

Обробка:
на початку ходу ворога

Формула:
mob.hp -= effect.damage
effect.turns -= 1

9.4. HoT

Обробка:
на початку ходу гравця

Формула:
current_hp = min(max_hp, current_hp + heal)
effect.turns -= 1

9.5. Shield

Обробка:
після атаки ворога, перед зменшенням HP

Формула:
absorbed = min(absorb_left, incoming_damage)
incoming_damage -= absorbed
absorb_left -= absorbed

Якщо:
absorb_left <= 0

щит видаляється.

16. Що ще потрібно зробити

16.1. Етап 5.4 — тестування балансу класів

Потрібно протестувати:

1. Скільки ходів кожен клас вбиває звичайного моба.
2. Скільки ходів кожен клас вбиває елітного моба.
3. Скільки HP втрачає кожен клас.
4. Чи не занадто сильна Вогняна куля.
5. Чи не занадто сильний Удар підкорення.
6. Чи не занадто сильне Потрошіння на 3 комбо.
7. Чи не занадто сильний щит Лицаря.
8. Чи комфортний HoT Жреця.
9. Чи нормальна економіка MP.
10. Чи не занадто багато контролю через stun.

16.2. Можливі баланс-правки

Лють:
+15 за атаку → +10
+10 за отримання шкоди → без змін
Удар підкорення: зменшити scaling

Енергія:
+20 енергії за хід → +15
вартість сильних навичок +5/+10
cooldown-и +1

Комбо:
Поточне scaling Потрошіння:
+45% за комбо

Можна змінити:
+35% якщо занадто сильне
+55% якщо слабке

Мана:
Поточне правило:
100% MP після бою

Можливі майбутні варіанти:
звичайний бій: +50% MP
елітний бій: +100% MP
смерть: +100% MP
втеча: +0–25% MP

18. Рекомендований найближчий план

Короткостроково:

1. Зробити git commit стабільної версії.
2. Провести тестування 6 класів.
3. Зібрати статистику боїв.
4. Внести баланс-правки.

Після тестів:
5.4.1 — баланс класів
5.5 — покращення UI навичок
5.6 — класи + екіпірування
6.0 — типи броні
7.0 — заточка
8.0 — боси


19. Контрольна точка поточного стану

Поточну стабільну версію варто зафіксувати як:
classes_full_skills_v1

Команда:
git add .
git commit -m "classes full skills v1"
git push

Це буде контрольна точка перед балансуванням.
