# Stage 18.31.4: Дата реєстрації

Додано canonical `users.registered_at` у UTC ISO-8601. Нові акаунти отримують точний timestamp першого створення. Повторний `/start` і DEV reset його не змінюють. Для legacy-акаунтів migration 052 записує час початку canonical обліку, оскільки точну історичну дату відновити неможливо.
