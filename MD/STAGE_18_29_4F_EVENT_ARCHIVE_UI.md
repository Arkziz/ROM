# ROM Stage 18.29.4f: Event Archive UI

Adds a read-only cross-event archive to the stabilized Events card. The archive uses the registered event catalog, orders active, upcoming and completed events, and shows five entries per page. Only completed events can be opened as historical cards. Historical cards show immutable event metadata and provide read-only access to the event leaderboard. The pilot event is not falsely archived while its dates remain pending. Existing session ownership, stale callback protection and the unique Events exit button are preserved.
